# Timeline App – JS School Project by Niranjana Y D

A responsive and theme-switchable timeline web app built using HTML, CSS, and JavaScript. It visually represents a project's milestones and phases with an elegant vertical timeline layout and dynamic theme support.

##  Features

- Clean, responsive UI with Poppins font
- Light/Dark theme toggle
- Vertical timeline with color-coded stages
- Hover animation and Read More functionality
- Modular and scalable code structure
- Fully accessible and mobile-friendly
